# The Lantern Below — tabletop maps

Original vector artwork authored for this repository on 2026-10-02. No stock
assets, remote resources, fonts, scripts, or third-party images are embedded.
These SVGs follow the repository's license.

Each file is **960 × 640 pixels**, for a **12 × 8 cell** scene at **80 pixels per
cell** and **5 feet per cell**. The tactical map supplies grid lines, tokens,
targeting, and interaction overlays. The maps intentionally contain no baked-in
grid, combat labels, or token positions.

- `landing.svg`: salt-worn lighthouse landing and shallow tidal wash.
- `hall.svg`: keeper's timber hall, teal runner, and maritime instruments.
- `archive.svg`: shallow flooded stone archive, books, and supply chest.
- `stair.svg`: sheltered stone landing, edge stair treads, and rest supplies.
- `beacon.svg`: brass-inlaid beacon floor and dormant lantern mechanism.
- `return.svg`: the original landing with warmer dawn light after either ending.

All artwork is decorative. Water is shallow; rugs, brass rings, stone joints,
and edge furnishings do not establish collision or cover. Center floors remain
open, supporting party staging on the left and enemies on the right. The outer
dark line is an illustration frame. Scene bounds and movement legality remain
the backend's responsibility. Each SVG includes an accessible title and
description and works without external dependencies.
